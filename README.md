# Teste Dev CSharp

Projeto desenvolvido em **ASP.NET Core MVC** como parte de um processo seletivo.

## Funcionalidades

- Cadastro de usuários
- Cadastro de endereços
- Busca automática de CEP utilizando a API ViaCEP
- Interface responsiva
- Persistência de dados em SQL Server

## Tecnologias Utilizadas

- ASP.NET Core MVC
- C#
- SQL Server
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Como executar

1. Clone o repositório.
2. Configure a string de conexão com o SQL Server no `appsettings.json`.
3. Execute o script de criação das tabelas.
4. Execute o projeto pelo Visual Studio.
